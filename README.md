# KaiOS 11 

**A custom desktop simulator built with Python and PySide6.**

Welcome to KaiOS 11! This project brings a desktop-style experience to life with its own interface, applications, games, wallpapers, and user account system.

##  Features

- **Custom desktop:** App tiles, Start menu, taskbar, and search.
- **User accounts:** Create accounts and sign in with a username and password.
- **Web browser:** Browse websites using an embedded web engine.
- **KaiOS Store:** Install and uninstall optional KaiOS applications.
- **Wallpapers:** Choose from colorful gradients, neon designs, and fantasy landscapes.
- **Desktop files:** Manage files inside the KaiOS environment.
- **Photo editor:** Edit images with drawing, text, and adjustment tools.
- **Games:** Play Snake, Space Explorer, Adventure Quest, Kai Racing, and Crystal Match.
- **More apps:** Calculator, Calendar, Notepad, and productivity tools.
- **Fullscreen mode:** Press F11 to switch fullscreen on or off.

## Installation

### Requirements

- Windows
- Python 3
- Required Python packages listed in `requirements.txt`

### How to start

1. Download the repository using **Code --> Download ZIP**.
2. Extract the downloaded ZIP.
3. Open the `KaiOS 11/KaiOS11` folder.
4. Install the dependencies:

   `python -m pip install -r requirements.txt`

5. Run KaiOS 11:

   `python kaios.py`

You can also try the included Windows batch launcher.
